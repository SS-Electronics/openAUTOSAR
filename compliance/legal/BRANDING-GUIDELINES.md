# Branding Guidelines

Status: preliminary engineering control.

`openAUTOSAR` is the working repository name. Public commercial branding remains
subject to trademark review.

## Approved Language

- Adaptive Platform-oriented runtime
- R22-11-oriented behavior baseline
- compatibility target
- conformance-oriented test environment
- project-owned implementation

## Restricted Language

Do not claim certification, official status, standards-body endorsement,
customer approval, or complete conformance without signed review evidence.

## Naming Rules

- Keep project-specific APIs under `openautosar::*`.
- Do not place project extensions in `ara::*`.
- Mark project-specific behavior as an extension or deviation.
- Keep customer, supplier, and partner names out of public claims unless a
  contract or approval record permits the wording.

## Release Gate

Each public release must review README text, package metadata, CLI output,
release notes, OEM export manifests, SBOM metadata, and web copy for restricted
claims before publication.
