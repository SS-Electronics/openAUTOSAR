# AUTOSAR IP Assessment

Status: preliminary engineering control.

This project is an original Adaptive Platform-oriented implementation effort.
It does not grant rights to redistribute AUTOSAR work products, schemas,
trademarks, copied requirement text, or proprietary OEM artifacts.

## Source Boundary

- Project-authored code, tests, tools, examples, and policies use the project
  license unless a file states otherwise.
- Public requirement tracking may reference document names, release identifiers,
  and requirement identifiers.
- Specification prose, AUTOSAR XML schemas, downloaded PDFs, proprietary ARXML,
  customer profiles, and confidential integration data must remain outside this
  repository unless redistribution rights are approved in writing.

## Release Gate

A release may not make conformance, certification, endorsement, or customer
approval claims until legal counsel has reviewed:

- source provenance;
- generated model inputs;
- specification and schema handling;
- trademark usage;
- OEM export contents;
- third-party license obligations;
- contribution records and sign-offs.

## Evidence

Required evidence is tracked through the release profile, deviation inventory,
license scan, OEM export manifest, SBOM, and this legal package.
