# Release Approval Checklist

Status: preliminary engineering control.

Use this checklist before a public release, OEM export, or customer delivery.

## Required Checks

- [ ] Legal review recorded for branding, trademark, and public claims.
- [ ] Release profile pins the Adaptive Platform behavior baseline.
- [ ] Deviation inventory is present and reviewed.
- [ ] License scan passes.
- [ ] Compliance validator passes.
- [ ] Model generation is reproducible.
- [ ] Unit, integration, and release tests pass.
- [ ] Yocto layer metadata validation passes.
- [ ] QEMU and network-lab evidence is collected when in scope.
- [ ] OEM export manifest, artifact inventory, and SBOM are generated.
- [ ] Third-party notice obligations are reviewed.
- [ ] No confidential model, customer, key, or credential material is staged.
- [ ] Release notes identify unsupported and deferred behavior.
