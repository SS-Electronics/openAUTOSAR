# Contributing

Contributions must be original work or compatible open-source work with clear
license provenance.

Rules for this repository:

- use `SPDX-License-Identifier: MIT` in project-authored source files where the format permits it;
- do not commit AUTOSAR specifications, schemas, copied requirement text, downloaded PDFs, proprietary ARXML, credentials, keys, or OEM-confidential material;
- keep Adaptive Platform behavior release-pinned through project-owned requirement references;
- add tests with functional changes;
- keep generated files clearly marked and reproducible from controlled inputs.

Commits should include a Developer Certificate of Origin sign-off:

```text
Signed-off-by: Name <email@example.com>
```
