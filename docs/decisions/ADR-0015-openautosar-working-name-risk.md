# ADR-0015: openAUTOSAR Working-Name Risk Acceptance

## Status

Accepted

## Context

The repository uses `openAUTOSAR` as a working name while legal and branding
boundaries remain active project risks.

## Decision

Accept `openAUTOSAR` as the current working repository name. Public commercial
branding and trademark-sensitive claims remain restricted by compliance policy.

## Consequences

The name may change before public productization. Legal work products must keep
the risk visible in package and OEM evidence.

## Evidence

- `compliance/legal/BRANDING-GUIDELINES.md`
- `compliance/legal/AUTOSAR-IP-ASSESSMENT.md`
- `scripts/validate-compliance.sh`
