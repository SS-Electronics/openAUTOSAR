# Security Policy

Do not report security issues through public issues before coordinated handling.

For now, keep reports private to the maintainer and include:

- affected commit or release;
- reproducible steps;
- expected and observed behavior;
- logs, packet captures, or test inputs when safe to share;
- whether secrets, keys, credentials, or signed artifacts are involved.

Security-sensitive code must use reviewed cryptographic providers. This project
does not implement custom cryptographic algorithms.
