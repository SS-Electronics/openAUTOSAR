# Bosch Supplier Adapter

This directory is a configurable adapter template layered on the generic
supplier delivery workflow. It does not represent confidential Bosch workflow
details and does not attempt to reverse-engineer proprietary process behavior.

Use this adapter only with actual project requirements, naming rules, input
contracts, ARXML mappings, quality gates, and report templates supplied through
authorized channels.
